# Senior Dev Interview Prep - PHP/Laravel + React + Vue

An interactive single-page application for preparing for senior developer technical interviews covering **PHP 8**, **Laravel**, **React**, and **Vue 3**.

## Quick Start

```bash
# Just open in your browser - no build step needed
open index.html
```

No dependencies. No npm install. No build tools. Just open the HTML file.

## What's Inside

### 22 Interactive Sections

| Category | Topics |
|----------|--------|
| **PHP 8 Core** | PHP 5/7/8 differences, named args, match expressions, enums, fibers, readonly classes, union types, null-safe operator, OOP, SOLID principles, design patterns, security, performance |
| **Laravel** | Service Container, Providers, Middleware, Eloquent (all relationship types), N+1 problem, Queues, Events, Jobs, Observers, Policies & Gates, Sanctum auth, Action pattern, API Resources, caching, testing |
| **React** | Hooks (useState, useEffect, useRef, useReducer), Context API, custom hooks, HOC, render props, compound components, error boundaries, React.memo, useMemo/useCallback, code splitting, Virtual DOM, Fiber, SSR |
| **Vue 3** | Composition API, ref vs reactive, watchers, composables, Pinia (vs Vuex), Vue Router, SSR & hydration, performance optimization |
| **System Design** | Full e-commerce architecture walkthrough, database schema design, scaling strategies, trade-off discussions |
| **DevOps** | Docker for Laravel, CI/CD with GitHub Actions, production optimization checklist |

### Practice & Assessment

- **35 Quiz Questions** — 15 PHP/Laravel, 10 React, 10 Vue (with detailed explanations)
- **4 Coding Challenges** — with hints, auto-checking, and full solutions:
  1. Laravel: Cached Repository (Decorator pattern)
  2. React: Custom Hook with debounce + request cancellation
  3. Vue: Pagination composable
  4. Laravel: Rate limiting middleware
- **10 Mock Interview Q&A** — senior-level questions with model answers
- **Learning Resources** — curated links for each technology

## Features

- Dark theme, mobile-responsive design
- Sidebar navigation with technology-grouped sections
- Interactive quizzes with instant grading and explanations
- Code editors with Tab support for challenges
- Accordion-based content for progressive disclosure
- No external dependencies — runs entirely offline
